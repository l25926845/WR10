# WR10 — 全屏开始菜单

仿 Windows 10 全屏开始菜单的 WPF 桌面应用。纯 .NET 10 实现，**零 NuGet 依赖**，所有能力（图标提取、布局持久化、虚拟化面板）均为手写实现。

## 功能特性

- **多尺寸磁贴网格**：支持 1×1 / 2×2 / 4×2 / 4×4 四种磁贴档位，按 Win10 开始菜单风格排布
- **分组管理**：新建 / 重命名 / 删除分组、磁贴跨组拖拽移动、组排序
- **磁贴拖拽**：按下超过阈值进入拖拽模式，松手落位，不影响单击启动
- **搜索**：输入即时过滤，磁贴化结果展示，方向键导航 + 回车启动
- **所有应用**：按字母分组的完整应用列表，右侧字母索引条快速跳转
- **全局热键**：`Ctrl+Alt+Space`（被占用时自动回退 `Ctrl+Alt+S`），随时唤起 / 收起
- **布局持久化**：磁贴布局保存为 JSON，重排 / 换组 / 改名后自动落盘

## 内存优化

针对"全部磁贴一次性实例化导致内存膨胀"的问题做了系统性虚拟化改造：

| 优化项 | 改造前 | 改造后 |
|---|---|---|
| 主磁贴区容器数 | 376 个全部实例化 | 仅可视区 75~108 个，滚动即回收 |
| 搜索结果 | 结果全量生成 | 仅可视区约 60 个容器 |
| 所有应用列表 | 403 行全量生成 | 仅可视区约 30 个容器 |
| 图标加载 | 启动排队全部 376 个 | 滚动进入可视区才加载 |
| 磁贴画刷 | 每次读取新建实例 | 按颜色缓存 + Freeze，全应用共享 |

### 虚拟化实现要点

- 自研 `VirtualizingTilePanel`：继承 `VirtualizingPanel` 并实现 `IScrollInfo`，在 `MeasureOverride` 中计算多尺寸网格布局，只对可视行（含 1 行缓冲）生成容器，滚出视野立即通过 `IItemContainerGenerator.Remove` 回收
- 分组标题通过 `GroupHeaderItem` 与磁贴扁平混排在同一 `ListBox` 中，标题独占整行并强制下一组另起一行，避免"填空"式布局错乱
- 面板在容器生成时触发 `ItemRealized` 事件，宿主据此按需解析图标，滚动性能与内存占用解耦

## 构建与运行

```powershell
dotnet build M0/FullScreenStart.csproj
dotnet run --project M0
```

环境要求：Windows 10+ / .NET 10 SDK。`Ctrl+Alt+Space` 唤起或收起菜单。

## 项目结构

```
M0/
├── VirtualizingTilePanel.cs   # 虚拟化磁贴面板（核心）
├── MainWindow.xaml(.cs)       # 主窗口：布局、交互、图标按需加载
├── AppCatalog.cs              # 开始菜单应用扫描与图标提取
├── LayoutStore.cs             # 磁贴布局持久化（JSON）
├── AllApps.cs                 # 所有应用数据模型与字母分组
└── NamePrompt.xaml(.cs)       # 分组命名对话框
```
